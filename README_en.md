# authenticity-of-passports-and-driver-s-ID-cards
A free, open source directory of official links to the PRADO (ID cards, passports, driving licences) and UNECE (ADR certificates) registers — for 55 ADR contracting parties. Makes it easy to quickly verify the identity and credentials of professional drivers.

# Identity Document and ADR Certificate Authenticity Check
**last updated: September 2026**

Amid rapidly growing dangerous-goods transport volumes and rising terrorist threat levels across the European Union, rigorous identity verification of transport personnel has become a critical link in risk mitigation. This is especially true when collecting shipments classified under the ADR Agreement as high-consequence dangerous goods or substances listed as [explosives precursors](https://eur-lex.europa.eu/legal-content/EN/ALL/?uri=CELEX%3A32019R1148). Among the layered preventive procedures, the baseline action remains verifying the crew's identity documents (passports, ID cards) and ADR credentials.

In the absence of a unified verification system (as of 2026), this project is an open directory redirecting to authoritative external registers — the European [PRADO](https://www.consilium.europa.eu/prado/) database and [UNECE](https://unece.org/transport/dangerous-goods/adr-certificates) resources.

## Countries with incomplete registry data

These are not bugs in this site — the sources (PRADO/UNECE) simply haven't published a specimen for some countries yet.

**No document specimen in PRADO:** Andorra (ID card), Armenia (ID card), Azerbaijan (ID card), Denmark (ID card), Iceland (ID card), Ireland (ID card), Kyrgyzstan (ID card), Nigeria (ID card), Russia (ID card), Turkey (ID card), Uganda (ID card and driving licence), Uzbekistan (ID card).

**No ADR certificate in the UNECE register:** Andorra, Armenia, Cyprus, Iceland, Liechtenstein, Morocco, Nigeria, Tajikistan, Tunisia, Uganda.

**Additional notes:**
* Croatia — the ADR certificate image in the UNECE register shows a stripe on the left side; this comes from an external program, not the official document itself.
* Netherlands — 3 different ADR certificate templates are currently in circulation (logo changed once, then the template itself).
